# 列車管理システム - Discord Bot連携版（v3）

## ファイル構成
- `server.js` … Webサーバー本体（静的配信・IP BAN・Groqプロキシ）
- `discord-bot.js` … Discord Bot本体（管理コマンド）
- `firebaseClient.js` … 両者共通のFirebase初期化（クライアント用SDK）
- `roomUtils.js` … 両者共通の部屋関連ユーティリティ
- `index.html` … Web画面（Groq呼び出し先を `/api/groq` に変更済み）

## Renderに設定する環境変数（2つだけ）

| 変数名 | 内容 |
|---|---|
| `DISCORD_TOKEN` | Discord Botのトークン |
| `GROQ_API_KEY` | GroqのAPIキー（**index.htmlに直書きされていた値は既に外部に公開済みなので、Groqのコンソールで必ず再発行してから設定してください**） |

`API_SECRET_KEY` は使用しません。BotはWebサーバーのAPIを経由せず、`firebaseClient.js` を通じて直接Firebaseを読み書きします。

## 今回追加した内容

### 1. コマンドの実行権限（ロール制限）
ロールID `1510405214811852900` を持つメンバーのみ、管理コマンドを実行できます。持っていないメンバーがコマンドを打っても何も反応しません（無視）。

### 2. 変更ログの送信
`!expand` `!leave` `!ipban` `!unipban` の実行後、チャンネルID `1526289865719943329` へ以下を含む通知を送信します。
- 実行されたコマンド
- 変更内容（例: どの部屋を何時間延長したか、どのIPをBANしたか）
- 実行者（メンションと実際のユーザー名）

`!ips` `!ipbanlist` は閲覧のみで状態を変更しないため、ログ送信の対象外です。

### 3. Firebaseの同期方式
サービスアカウント鍵は使わず、index.htmlと同じ「クライアント用Firebase SDK」を`firebaseClient.js`にまとめ、Bot・サーバーの両方から利用しています。Botが部屋データを書き換えると、index.html側の既存のリアルタイムリスナーがそのまま検知してWeb画面に即座に反映されます。

### 4. Groq APIキーの保護
これまで `index.html` に直接書かれていたGroqのAPIキーは削除しました。Web画面からのGroq呼び出しは `/api/groq`（`server.js`内）を経由し、キーはサーバーの環境変数としてのみ保持されます。
- リクエストは1件ずつ順番に処理するキューを通します（同時多発によるレート制限を予防）。
- Groqから429（レート制限）が返ってきた場合、`Retry-After`ヘッダー、もしくは指数バックオフ（1秒→2秒→4秒→8秒、最大4回リトライ）で自動的に再試行します。

## ⚠️ 重要: 今すぐ対応してほしいこと
アップロードいただいた元の`index.html`には、有効なGroqのAPIキーがそのまま書かれていました。このキーは既にインターネット上に公開されていたのと同じ状態です。**Groqのコンソール（console.groq.com）で、このキーを無効化して新しいキーを再発行し、その新しいキーをRenderの`GROQ_API_KEY`に設定してください。**

## Discordコマンド（変更なし）
管理チャンネル（`1524877240628805763`）で、必要なロールを持つメンバーが実行します。

- `!expand 部屋1 2h` … 部屋1の有効期限を2時間延長
- `!expand VIP1 1d` … VIP1の有効期限を1日延長
- `!leave 部屋1 悪用` … 部屋1を強制解散し、作成者へDM通知（見つからない場合は記録IPを表示）
- `!ips` … 現在利用中＋過去30日の履歴のIP一覧
- `!ipban 192.168.1.100` … 指定IPをBAN
- `!unipban 192.168.1.100` … BAN解除
- `!ipbanlist` … BAN中のIP一覧

## 補足
- IP BANは最大15秒程度でBAN状態が反映されますが、既にブラウザを開いてFirebaseとリアルタイム接続中の相手を強制切断することはできません。
- `!leave`でユーザーが見つからない場合、記録されたIPアドレスを表示するのみで、そこから個人を特定する機能は実装していません。
